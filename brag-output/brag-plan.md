# /brag plan: Cue Space

**What it is:** A Mac app that opens everything an activity needs in one click.
**For:** Students and makers who juggle tabs, apps and folders for every task.
**What sets it apart:** You describe an activity (or build it by hand); starting it opens and *arranges* everything, never using AI. Claude can build Cues too.
**Hook:** "Your Mac thinks in apps. You think in activities." Scattered app/tab chips snap into one Cue.
**Tone:** `default`: punchy, clean, confident. Brand: Night `#111113`, Cue Red `#D93025`, Geist.
**Share caption:** Your Mac thinks in apps. You think in activities. Cue Space opens everything you need for one, in one click.

All data on screen is fictional (Atlas, Linear Algebra, course.example.edu). The UI shots are the real React app rendered with mock services.
